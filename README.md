一款运行于 Windows 的桌面图片格式转换工具。用户把图片拖进窗口，选择目标格式和输出目录，
即可完成单个或整批图片的格式转换；转换过程中可以顺带缩放、旋转、翻转、灰度化和调整颜色
通道，并查看历史记录与运行日志。

## 功能特性

- **单文件转换**：拖放或点击选择一张图片，实时预览、立即转换。
- **批量转换**：一次添加多张图片，后台多线程并发处理，逐条显示成功/失败状态与耗时。
- **图像变换**：缩放（最近邻 / 双线性）、灰度化、水平翻转、垂直翻转、旋转 90°/180°/270°、
  颜色通道转换（灰度、灰度+透明、真彩色、真彩色+透明）。
- **输出控制**：可选目标格式、输出目录、命名规则（沿用原文件名 / 追加 `_converted` 后缀 /
  追加时间戳）以及同名文件是否允许覆盖。
- **格式自动识别**：先按扩展名判断，再用文件头魔数嗅探，最后穷举解码器尝试，逐级兜底，
  扩展名写错也能正确读入。
- **历史记录**：自动记录每次转换的来源、目标、结果与耗时，最多保留 500 条，可检索与清空。
- **设置**：界面主题、并行线程数、是否保留历史记录，修改后立即生效并保存。
- **运行日志**：界面内显示最近日志，同时写入应用数据目录，超过 1 MB 自动轮转。

## 支持的图片格式

已实现读写的 8 种格式：

| 格式 | 关联扩展名 | 说明 |
| --- | --- | --- |
| BMP | `bmp` `dib` | Windows 标准位图，支持 8/24/32 位 |
| Netpbm | `pbm` `pgm` `ppm` `pnm` `pam` | 含 PBM/PGM/PPM/PAM 四类；写出扩展名随颜色模式取 `pgm`/`ppm`/`pam` |
| PNG | `png` | 无损压缩，支持透明度与 16 位色深；压缩等级可调（0–9） |
| JPEG | `jpg` `jpeg` `jpe` | 有损压缩，质量可调（1–100）；不支持透明度 |
| TGA | `tga` `targa` `icb` `vda` `vst` | 支持灰度与真彩色，可选用 RLE 压缩 |
| QOI | `qoi` | 面向快速编解码的现代无损格式 |
| farbfeld | `ff` | 16 位每通道的高精度无损格式 |
| ICO | `ico` | Windows 图标容器，最大支持 256×256 |

8 种格式可互相转换，共 64 组组合（同格式另可作为「重编码」使用）。`GIF` 计划于下一版本支持。

## 构建与运行

环境要求：Windows 10/11（64 位）、Rust 1.85 或更高版本（edition 2024，目标平台
`x86_64-pc-windows-msvc`）。图片编解码依赖 `image` 0.25（仅启用本项目用到的 8 个格式特性），
界面使用 `eframe`/`egui`，无需额外安装系统组件。

```bat
:: 编译
cargo build --release

:: 运行
cargo run --release

:: 运行并载入待转换文件
cargo run --release -- "D:\图片\a.png" "D:\图片\b.bmp"
```

产物为 `target\release\r-format-converter.exe`，可直接运行。

测试与静态检查：

```bat
cargo test --all-targets
cargo clippy --all-targets -- -D warnings
```
